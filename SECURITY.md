# Security policy

Animal Helper handles potentially sensitive allegations, locations, contact
details, and media. Do not report a vulnerability in a public issue.

Until the project has a dedicated security mailbox, use GitHub's private
**Report a vulnerability** function (a private security advisory) on this
repository. If that function is unavailable, contact the repository owner
privately and share only the minimum detail needed to establish a secure
channel.

Include:

- the affected component and version or commit;
- reproduction steps using synthetic data;
- likely impact;
- any suggested remediation.

Do not access, download, retain, or alter real reports while testing. Do not
test denial-of-service techniques against production services.

The maintainers will acknowledge a valid private report as soon as volunteer
capacity allows. A formal response-time policy will be published before a public
launch.
